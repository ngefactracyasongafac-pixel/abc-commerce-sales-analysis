# ABC Commerce Sales Analysis

An Excel-based sales analysis project completed as a simulated client project.

## Project Overview

This project analyzes 5,000 e-commerce transactions to prepare sales data, calculate key performance indicators, identify revenue patterns, and create a management dashboard.

## Tools Used

- Microsoft Excel
- Data cleaning and validation
- Excel formulas
- Conditional calculations
- PivotTables
- Charts and dashboard design

## Analysis Completed

- Checked the dataset for missing values and duplicates
- Prepared and validated the sales data
- Calculated key business metrics
- Analyzed revenue by product category
- Analyzed revenue by region
- Performed multi-condition analysis
- Created PivotTables
- Created a summary of key findings
- Built an interactive Excel dashboard

## Key Results

- **Total Revenue:** 5,109,775.74
- **Total Transactions:** 5,000
- **Total Quantity Sold:** 20,224
- **Average Revenue per Order:** 1,021.96
- **Highest Revenue Category:** Electronics — 1,829,899.22
- **Highest Revenue Region:** West — 1,345,582.16
- **Lowest Revenue Category:** Beauty — 765,860.88

## Business Recommendations

- Continue monitoring the strong performance of the Electronics category.
- Investigate the factors contributing to the West region's high revenue.
- Review the performance of the Beauty category and identify opportunities for improvement.
